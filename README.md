# Portfolio — Abdullahi Abdulmajeed

Simple dark portfolio site.

## Deploy on Netlify (fastest way)

1. Go to [app.netlify.com](https://app.netlify.com)
2. Drag and drop this entire `portfolio` folder
3. Done. You’ll get a free `*.netlify.app` link

Or connect your GitHub repo if you prefer.

## Local preview

Just open `index.html` in any browser.
